# Portfolio Website

A modern, impressive portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- 🎨 Modern dark theme with blue/purple accents
- ✨ Smooth animations and micro-interactions
- 📱 Fully responsive design
- 🚀 Fast and optimized with Vite
- 🎯 Single-page experience with smooth scrolling

## Sections

- **Hero** - Engaging introduction with animated heading
- **About** - Personal story and background
- **Featured Experience** - BSE internship highlights
- **Projects** - Showcase of major projects with awards
- **Skills** - Organized skill categories with icons
- **Achievements** - Major wins and recognitions
- **Timeline** - Interactive chronological journey
- **Contact** - Contact form and social links

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Lucide React** - Icon library

## Customization

Update the content in each component file to personalize:
- `src/components/Hero.jsx` - Main hero section
- `src/components/About.jsx` - About section content
- `src/components/FeaturedExperience.jsx` - Experience details
- `src/components/Projects.jsx` - Project cards
- `src/components/Contact.jsx` - Contact information

### Profile Image

To add your profile image to the About section:
1. Place your image file as `profile.jpg` in the `public/assets/` folder
2. The image will automatically appear with a premium hover effect (grayscale to color transition)
3. Supported formats: JPG, PNG, WebP
4. Recommended size: 400x500px or larger (will be scaled responsively)
